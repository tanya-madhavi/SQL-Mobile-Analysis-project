# SQL Mobile Analysis Project

## 📌 Project Overview

This project focuses on analyzing **mobile sales data using SQL Server** to extract meaningful business insights. SQL queries are used to explore the data, perform calculations, filter information, and analyze different aspects of mobile sales.

## 🎯 Objective

The main objective of this project is to use SQL for **data analysis and business problem-solving** by identifying patterns, trends, and useful insights from mobile sales data.

## 🛠️ Tools & Technologies

* SQL Server
* T-SQL

## 📊 Analysis Performed

* Data exploration and filtering
* Aggregation and summary analysis
* GROUP BY and HAVING
* Different types of JOINs
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Ranking and comparison analysis
* Business-oriented data analysis

## 🔑 SQL Concepts Used

* SELECT, WHERE, DISTINCT
* ORDER BY
* GROUP BY and HAVING
* Aggregate Functions
* CASE WHEN
* INNER JOIN
* LEFT JOIN
* SELF JOIN
* Subqueries
* CTE
* Window Functions
* RANK
* DENSE_RANK
* ROW_NUMBER
* LAG and LEAD

## 💡 Key Insights

The analysis helps understand mobile sales performance, compare different products and categories, identify top-performing products, and derive useful business insights from the available data.
